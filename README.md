### 💰 SajiloSplit — Smart Digital Money Management Platform

A full-stack fintech application built for Nepal — combining digital wallet, group expense splitting, shared budgets, settlements, bill management, and purpose-locked funds.

**Tech:** React.js • Vite • Tailwind CSS • Redux Toolkit • Node.js • Express.js • MongoDB • JWT • Socket.IO

**Highlights:**
- 🔐 Bank-level security (JWT, bcrypt, rate limiting, account lockout, device fingerprinting)
- 💰 Digital wallet with send/receive, transaction history, PDF export, QR payments
- 👥 Group wallet with smart expense splitting (Equal, Percentage, Exact, Shares)
- ⚖️ Auto-settlement optimization algorithm
- 📊 Budget tracking, bill management, locked funds, emergency funds
- 🛡️ KYC verification with admin approval
- 👑 Admin dashboard with full platform management
- 🌍 12 languages + dark mode + real-time notifications

🔗 [View Repository](https://github.com/acharyanisha1234/SajiloSplit)
